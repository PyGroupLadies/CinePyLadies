# CinePyLadies

## 1. Descrição
 
<br />
 
O projeto **CinePyLadies** é um sistema feito em grupo que permite que usuários cadastrem, visualizem, editem, filtrem e excluem filmes. Este projeto foi desenvolvido com fins educacionais, simulando um sistema real de catálogo de filmes para praticar conceitos de programação orientada a objetos com Python, controle de versionamento com Git e GitHub e principalmente comunicação, gestão de tempo e trabalho em equipe.
 

<br />

<br />
 
| Item                          | Descrição       |

## 4. Como Executar o projeto no VS Code
 
<br />
 
### 4.1. Importando o Projeto
 
1. Clone o repositório do Projeto [CinePyLadies]([https://github.com/Giovanalucia/blogpessoal_spring](https://github.com/PyGroupLadies/CinePyLadies)) dentro do terminal do VS Code
 
```bash
git clone https://github.com/PyGroupLadies/CinePyLadies.git
```
2. Entre dentro da pasta **CinePyLadies**
```bash
cd CinePyLadies
```
3. Entre dentro da outra pasta **src**
```bash
cd src
```
4. Dê o seguinte comando no terminal para o sistema funcionar
```bash
python main.py
```
